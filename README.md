## 📖 Overview

The **Elswedy Attendance Backend API** powers the biometric attendance operations for **Elswedy International Applied Technology Schools (IATS)**.

- **Primary Production Engine (.NET 10)**: Located in [`backend-aspnet/`](../backend-aspnet/), pre-compiled and published to **MonsterASP.net**.
- **Node.js Express Engine**: Contains legacy Node.js/TypeScript Express scripts and tools.
